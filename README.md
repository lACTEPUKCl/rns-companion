# RNS Companion — «Набор игроков»

Desktop-клиент режима **«Набор игроков»** на сервера Squad сообщества
[rnserver.ru](https://rnserver.ru). Windows · C# / WPF · .NET 8.

> Companion — техническое имя проекта (exe, репозиторий, задачи планировщика,
> протокол `rnscompanion://`). В интерфейсе фича называется «Набор игроков».

## Что такое набор игроков

Пустой сервер Squad никто не видит в браузере серверов — чтобы он «ожил», кто-то
должен зайти первым и подождать, пока сервер не наберёт ~60 игроков. Это и есть
набор (в народе — «сид»).

RNS Companion делает рутину за вас:

1. Сайт выбирает целевой (самый малонаселённый) сервер сообщества.
2. Приложение запускает Squad и ждёт записи о завершении загрузки
   `/Game/Maps/EntryMap` в `%LocalAppData%\SquadGame\Saved\Logs\SquadGame.log`.
   Принимаются только записи не старше текущего процесса игры. После этого,
   пока сайт не подтвердил ваше присутствие на цели, приложение отправляет
   `steam://joinlobby/...` не чаще раза в две минуты на тот же сервер.
   Кнопка подключения к отдельному серверу также ждёт лог, обновляет ссылку
   после загрузки и отправляет её один раз. При отсутствии подтверждения
   она завершает ожидание через 10 минут; набор продолжает ждать с сообщением
   после 5 минут. Недоступный лог не заменяется фиксированной задержкой.
3. Как только вы на сервере — идёт сессия, за минуты начисляются бонусы
   (начисление — на стороне сайта, приложение только показывает прогресс).
4. Когда все серверы заполнены, приложение по настройкам закрывает игру
   и может увести ПК в сон.

## Возможности

- **Вход через сайт** — без паролей: открывается браузер, одноразовый код
  меняется на JWT, токен хранится в DPAPI (только ваш пользователь Windows
  может его расшифровать).
- **«Начать набор»** — ручной запуск цикла набора; живой таймер сессии,
  счётчик бонусов, спарклайн онлайна цели, журнал событий.
- **Расписание** — задача Windows Task Scheduler с опцией «будить компьютер»
  (WakeToRun): ПК проснётся ночью, поучаствует в наборе и снова уснёт.
  На время автоматического набора приложение удерживает систему от повторного
  сна; разблокировать Windows для работы сида не требуется.
- **Энергосбережение** (всё опционально): гашение мониторов, low-graphics
  пресет `GameUserSettings.ini` на время игровой сессии (с многослойной
  защитой вашего конфига — см. ниже), сон ПК после завершения.
- **Трей** — сворачивание в область уведомлений.

## Безопасность ваших настроек (GameUserSettings.ini)

Опция low-graphics подменяет `GameUserSettings.ini` на время игры. Squad при
выходе **перезаписывает этот файл содержимым из памяти**, поэтому подмена
организована так, чтобы ваш конфиг было практически невозможно потерять:

- **Подмена — только на время игровой сессии.** Пресет подкладывается
  непосредственно перед запуском игры и возвращается сразу после её полного
  закрытия (с паузой в несколько секунд — игра дописывает файл при выходе).
  Если игра уже запущена, подмена не выполняется вообще.
- **Два бэкапа с контрольной суммой.** Оригинал копируется и рядом
  (`GameUserSettings.rnsbak.ini`), и в `%LocalAppData%\RNS\Companion\backup\`.
  Перед восстановлением бэкап проверяется по SHA256; битый бэкап не
  используется. Без хотя бы одного валидного бэкапа подмена не начинается.
- **Watchdog-процесс.** Пока подмена активна, работает фоновый сторож:
  даже если убить приложение через диспетчер задач, сторож дождётся выхода
  игры и восстановит конфиг.
- **Страховка при входе в систему.** Задача планировщика
  «RNS Companion RestoreGuard» при каждом входе в Windows проверяет:
  если подмена осталась «висеть» — восстанавливает конфиг. Работает, даже
  если приложение больше ни разу не запускали.
- **Всё атомарно.** Любая запись INI — через временный файл, на полпути
  файл не окажется.

**Ручное восстановление** (если вообще всё пошло не так): откройте
`%LOCALAPPDATA%\SquadGame\Saved\Config\Windows` и переименуйте
`GameUserSettings.rnsbak.ini` в `GameUserSettings.ini` (с заменой).
Запасная копия лежит в `%LocalAppData%\RNS\Companion\backup\`.

## Что приложение НЕ делает

- **Не читает память игры** и никак с ней не взаимодействует, кроме запуска
  через Steam-ссылку и закрытия процесса по окончании набора.
- **Не модифицирует файлы игры**, кроме `GameUserSettings.ini` — и только
  при включённой опции low-graphics, с обязательным бэкапом
  (`GameUserSettings.rnsbak.ini`) и восстановлением.
- **Не собирает и не отправляет никаких данных**, кроме запросов к API
  сайта rnserver.ru (статус набора, включение/выключение режима). Базовый URL
  один, настраивается в настройках.
- **Не требует прав администратора** — регистрация протокола `rnscompanion://`
  и задача планировщика создаются от имени текущего пользователя.

## Установка

Скачайте `RNS.Companion.exe` из
[релизов](../../releases) и положите в любую папку — установка не требуется.

> При первом запуске Windows SmartScreen может показать «неизвестный издатель» —
> это нормально для неподписанных сборок: нажмите «Подробнее» → «Выполнить в любом
> случае». Готовится подпись кода сертификатом (см. ниже), после неё предупреждение
> исчезнет.

### Проверка SHA256

К каждому релизу приложен файл `RNS.Companion.exe.sha256`. Сверьте хеш:

```powershell
Get-FileHash .\RNS.Companion.exe -Algorithm SHA256
```

Хеш должен совпадать с содержимым `.sha256`-файла из релиза.

## Сборка из исходников

Нужен .NET SDK 8.0+:

```powershell
dotnet publish src/RnsCompanion/RnsCompanion.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

Готовый файл — `publish/RNS.Companion.exe` (~80 МБ, .NET встроен, отдельно
ничего ставить не нужно).

## Удаление

1. В настройках приложения выключите расписание (задача планировщика
   «RNS Companion» будет удалена) — либо удалите её вручную:
   `schtasks /Delete /TN "RNS Companion" /F`.
2. Если включали low-graphics, удалите страховочную задачу:
   `schtasks /Delete /TN "RNS Companion RestoreGuard" /F`.
3. Удалите `RNS.Companion.exe`.
4. Удалите данные приложения: `%LocalAppData%\RNS\Companion`
   (токен, настройки, логи, резервная копия конфига игры).
5. Опционально — регистрацию протокола: удалите раздел реестра
   `HKCU\Software\Classes\rnscompanion`.
6. Проверьте, что конфиг игры на месте: если приложение удалялось во время
   активной подмены, восстановите вручную — см. раздел «Безопасность ваших
   настроек» выше (файл `GameUserSettings.rnsbak.ini` рядом с конфигом игры).

## Подпись кода (Certum Open Source)

Релизные сборки подписываются сертификатом Certum (Open Source Code Signing,
облачный SimplySign) — снимает предупреждение SmartScreen «неизвестный издатель».
Подпись выполняет CI (`.github/workflows/ci.yml`) через
[dismine/windows-app-signing-setup-action](https://github.com/dismine/windows-app-signing-setup-action)
и работает только для релизов по тегу и только когда заданы секреты репозитория:

- `CERTUM_USERNAME` — логин аккаунта Certum (email);
- `CERTUM_OTP_URI` — TOTP URI (`otpauth://...`) из SimplySign;
- `CERTUM_KEY_ID` — SHA1-отпечаток сертификата.

Без секретов релиз собирается как раньше, просто без подписи.

## Как это работает внутри

- `Services/ApiClient.cs` — HTTP-клиент API сайта (Bearer JWT + CSRF
  double-cookie для мутирующих запросов).
- `Services/TokenStore.cs` — DPAPI-хранение токена (CurrentUser).
- `Services/ProtocolRegistration.cs` — регистрация `rnscompanion://` в HKCU.
- `Services/SingleInstanceService.cs` — один экземпляр: второй передаёт
  auth-URI первому через named pipe.
- `Services/SeedController.cs` — цикл набора: опрос `/api/seed/my` каждые
  30 с, дедупликация join (не чаще раза в 2 минуты на сервер), завершение.
- `Services/AtomicFile.cs` — атомарная запись настроек, токена и состояния сида.
- `Services/SchedulerService.cs` — задача планировщика: `schtasks.exe`
  (daily/weekly, per-user, без админки) + PowerShell `Set-ScheduledTask`
  для WakeToRun и остальных настроек (как в проверенном bat-подходе).
  Режимы: «каждый день» или выбранные дни недели + время; ПК будится из сна.
  Там же — страховочная задача RestoreGuard (при входе в систему).
- `Services/ConfigSwapService.cs` — подмена конфига игры строго на время
  игровой сессии: двойной бэкап с SHA256, маркер состояния, exit-watcher
  (restore после полного выхода игры).
- `Services/WatchdogService.cs` — detached-сторож (`/watchdog <pid>`):
  восстанавливает конфиг, если приложение убили во время подмены.
- `Services/PowerService.cs` / `GameProcessService.cs` — мониторы, сон,
  закрытие игры (CloseMainWindow → kill по таймауту).

Логи: `%LocalAppData%\RNS\Companion\logs`.

### Восстановление набора

Пока набор включён, временные ошибки API и таймауты не выключают цикл:
опрос повторяется через 30 секунд. Временная ошибка первоначального запуска
переводит Companion в ожидание сервиса/окна набора с повторами раз в минуту,
без ограничения количества попыток. «Стоп» отменяет ожидание.

При завершении процесса Squad приложение снова запускает игру и после загрузки
меню повторяет подключение. Критическая ошибка текущего запуска в SquadGame.log
вызывает закрытие и перезапуск игры. Страховочные пороги: 2 минуты без ответа
окна, 10 минут без загрузки меню, 15 минут без подтверждения входа после загрузки.
Повторный аварийный перезапуск возможен не чаще раза в 5 минут. Проверки
выполняются при успешном опросе API; во время его недоступности цикл ждёт связи.
Обычные попытки входа выполняются не чаще раза в 2 минуты.

Событие `HandleNetworkConnectionStatusChanged: NotConnected` текущего запуска
в логе также запускает восстановление после 2 минут без связи, если игрока нет
на целевом сервере. `Connected` отменяет эту причину перезапуска. Старые события
и непрочитанный до конца лог не используются для такого решения. Это покрывает
потерю связи с онлайн-сервисами у отвечающей игры; ошибки без этого события
остаются под общей страховкой 15 минут без подтверждённого входа.

Завершение требует явного `allSeeded=true`: пропавшая цель сама по себе не
выключает набор. Старый API без этого поля больше не вызывает автоматическое
завершение по отсутствующей цели. Истёкший токен требует повторного входа.

Проверка реального цикла с подменой API, процессов и системных действий
(не запускает и не закрывает настоящую игру, занимает около минуты):

```powershell
dotnet run --project tools/recovery-test/recovery-test.csproj -c Release
```

Быстрые тесты чистой логики:

```powershell
dotnet run --project tools/logic-test/logic-test.csproj -c Release
```
